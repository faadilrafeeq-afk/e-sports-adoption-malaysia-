## 🔧 TROUBLESHOOTING

**Charts not showing?**
- Check that `viz/` folder exists
- Check that JSON file names match exactly (lowercase, no spaces)
- Check browser console for errors (F12)

**Live Server not working?**
- Make sure Live Server extension is installed (VS Code Extensions)
- Right-click `index.html` and look for "Open with Live Server"

**JSON syntax error?**
- Paste each JSON spec into https://jsonlint.com/ to validate
- Make sure you copied the ENTIRE block (both opening and closing braces)
